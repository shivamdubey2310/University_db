# **Final_table_list**

| Table Name                 | Type        | Description                                                                                                                                                                                                                                                 |
| -------------------------- | ----------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Students**               | Data        | Stores official records of all individuals enrolled in the university as students. This table is important because it maintains the core personal and academic identity data used for all student-related processes and reporting.                          |
| **Faculty**                | Data        | Holds official records of all academic staff members of the university. This table is important because it supports faculty management, teaching assignments, and academic oversight responsibilities.                                                      |
| **Departments**            | Validation  | Contains the official list of academic departments recognized by the university. This table is important because it ensures consistency in departmental references across all academic and administrative records.                                          |
| **Courses**                | Data        | Maintains the official catalog of academic courses offered by the university. This table is important because it defines the curriculum and serves as the foundation for course planning, scheduling, and registration.                                     |
| **Rooms**                  | Data        | Stores information about all rooms available for academic activities within the university. This table is important because it enables efficient management of physical learning spaces and supports scheduling without conflicts.                          |
| **Majors**                 | Validation  | Contains the official list of academic majors available to students. This table is important because it standardizes major programs across records and supports academic planning and reporting.                                                            |
| **Minors**                 | Validation  | Contains the official list of academic minors available to students. This table is important because it standardizes minor programs across records and ensures accurate academic tracking.                                                                  |
| **Course\_Offerings**      | Transaction | Stores specific instances of courses being offered in a given semester, including faculty assignment, classroom allocation, and schedule details. This table is important because it supports real-time scheduling, registration, and timetable management. |
| **Course\_Offering\_Days** | Transaction | Captures the days of the week when each course offering occurs. This table is important because it resolves the multivalued “days\_of\_week” field into a normalized structure, ensuring accurate conflict checking and scheduling.                         |
| **Enrollments**            | Transaction | Records which students are enrolled in which course offerings, including grades. This table is important because it enables tracking of student academic progress, supports grading, and drives transcript generation and performance reporting.            |
